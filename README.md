# 🟡 Pac-Man Game

A classic-inspired arcade game built with **Python and Pygame**. Control Pac-Man, collect pellets, avoid ghosts, and chase a high score.

## 🎮 Gameplay

- Move with the arrow keys.
- Collect pellets to increase your score.
- Avoid the ghosts.
- Press **R** after game over to restart.

## ✨ Features

- Smooth keyboard controls
- Randomized ghost movement
- Live score tracking
- Bounded play area
- Game-over and restart flow

## 🛠️ Tech Stack

- Python 3
- Pygame

## 🚀 Installation

```bash
git clone https://github.com/Neetesh1541/Pac-man-game.git
cd Pac-man-game
pip install pygame
```

## ▶️ Run

```bash
python Pac-man.py
```

## 🎯 Controls

| Key | Action |
|---|---|
| ⬅️ | Move left |
| ➡️ | Move right |
| ⬆️ | Move up |
| ⬇️ | Move down |
| R | Restart after game over |
